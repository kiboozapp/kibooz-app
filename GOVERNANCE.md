# Tata Kelola

Kibooz App dikerjakan oleh tim kecil. Halaman ini menjelaskan bagaimana perubahan diterima, agar tidak ada yang perlu menebak. Repositori ini dimiliki organisasi [kiboozapp](https://github.com/kiboozapp). Orang yang terlibat tercatat di [MAINTAINERS.md](MAINTAINERS.md).

## Perubahan

Perubahan masuk ke `main` lewat pull request dari sebuah branch. Langkahnya ada di [CONTRIBUTING.md](CONTRIBUTING.md).

- Pull request boleh meminta `ArmJour`, `ValentinusMarvel`, `SyafaHadyan`, `FhmiSddq` atau `RozdanHanyv` sebagai reviewer.
- Pull request digabung oleh anggota tim yang punya izin menulis di repositori.
- Hanya merge commit yang diizinkan, sehingga setiap commit tetap ada di riwayat `main`.

## Pengecekan otomatis

Branch `main` dilindungi ruleset. Perubahan masuk lewat pull request, semua thread review harus diselesaikan, dan sebelas pengecekan wajib harus berhasil. Persetujuan review tidak wajib. Daftar lengkapnya ada di [docs/ci-cd.md](docs/ci-cd.md).

## Rencana kerja

Kebutuhan produk dan rencana kerja ada di folder `docs/prd_and_roadmap`. Lihat juga [ROADMAP.md](ROADMAP.md).

## Perilaku dan keamanan

Semua orang mengikuti [Code of Conduct](CODE_OF_CONDUCT.md). Kerentanan dilaporkan secara pribadi seperti dijelaskan di [SECURITY.md](SECURITY.md).

## Mengubah halaman ini

Perubahan pada halaman ini dan pada [MAINTAINERS.md](MAINTAINERS.md) masuk lewat pull request seperti perubahan lain.
