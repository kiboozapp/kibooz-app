# Tata Kelola

Kibooz App dikerjakan oleh tim kecil. Halaman ini menjelaskan bagaimana perubahan diterima, agar tidak ada yang perlu menebak. Orang yang terlibat tercatat di [MAINTAINERS.md](MAINTAINERS.md).

## Perubahan

Perubahan masuk ke `main` lewat pull request dari sebuah branch. Langkahnya ada di [CONTRIBUTING.md](CONTRIBUTING.md).

- Pull request boleh meminta `ArmJour`, `ValentinusMarvel`, `SyafaHadyan`, `FhmiSddq` atau `RozdanHanyv` sebagai reviewer.
- Pull request digabung oleh pemilik repositori atau anggota tim yang punya izin menulis di repositori.
- Kebiasaan tim adalah merge commit, sehingga setiap commit tetap ada di riwayat `main`.

## Pengecekan otomatis

Repositori ini tidak memiliki pengecekan wajib dan tidak memiliki aturan branch yang memblokir merge. Pengecekan otomatis, jika ada, hanya melaporkan hasil. Hasil yang gagal tidak menghalangi merge, tetapi sebaiknya diperbaiki sebelum pull request digabung.

## Rencana kerja

Kebutuhan produk dan rencana kerja ada di folder `docs/prd_and_roadmap`. Lihat juga [ROADMAP.md](ROADMAP.md).

## Perilaku dan keamanan

Semua orang mengikuti [Code of Conduct](CODE_OF_CONDUCT.md). Kerentanan dilaporkan secara pribadi seperti dijelaskan di [SECURITY.md](SECURITY.md).

## Mengubah halaman ini

Perubahan pada halaman ini dan pada [MAINTAINERS.md](MAINTAINERS.md) masuk lewat pull request seperti perubahan lain.
