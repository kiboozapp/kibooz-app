# Dukungan

Kibooz App dikerjakan oleh tim kecil. Tidak ada dukungan berbayar dan tidak ada janji waktu balasan. Halaman ini menjelaskan ke mana setiap jenis pertanyaan sebaiknya dikirim.

## Baca dulu

| Anda ingin tahu | Baca |
| :--- | :--- |
| Fitur yang ada dan cara membuka proyek | [README.md](README.md) |
| Rencana kerja dan kebutuhan produk | Folder `docs/prd_and_roadmap`, mulai dari `00_INDEX.md` |
| Cara mengirim perubahan | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Kontrak server yang dipakai aplikasi | Repositori [kibooz-backend](https://github.com/kiboozapp/kibooz-backend) |

## Ke mana setiap pertanyaan dikirim

- Bug. Buka issue dengan template Laporan bug. Jelaskan apa yang terjadi, langkah untuk mengulang, versi aplikasi, serta perangkat dan versi Android. Hapus data pribadi dan data login dari semua isian.
- Usulan atau fitur yang belum ada. Buka issue dengan template Permintaan fitur.
- Masalah keamanan. Jangan membuka issue publik. Ikuti [SECURITY.md](SECURITY.md).
- Hambatan aksesibilitas. Ikuti [ACCESSIBILITY.md](ACCESSIBILITY.md).
- Perubahan yang ingin Anda kerjakan sendiri. Baca [CONTRIBUTING.md](CONTRIBUTING.md) lebih dulu.
- Pertanyaan lain tentang proyek. Tanyakan kepada pemilik repositori `ValentinusMarvel` atau reviewer `ArmJour` di GitHub.

## Yang tidak didukung

Hanya kode di branch `main` yang ditangani. Membangun aplikasi dengan alamat API milik sendiri menjadi tanggung jawab Anda. Issue tetap diterima jika ternyata penyebabnya adalah bug di kode.
